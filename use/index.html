Use cases

Btwinus is an encrypted, one-on-one chat that runs in the browser with no account, no server, and no history. These are the situations it was built for.

  • Journalists and sources

    Receive anonymous tips from sources without a server trail. A first-contact channel that asks nothing of the source and keeps no record.

  • Lawyers and clients

    Encrypted lawyer–client chat with no firm server. Privileged conversations that live only in two browsers and vanish on close.

  • Secure negotiations

    Negotiate sensitive terms with no transcript. Salary, deals, and disputes discussed freely, with no identity required and nothing to forward.

  • Anonymous feedback

    Anonymous feedback channel with no account. Employees, students, and customers can be honest in a live chat that cannot be traced back to them.

  • Sending passwords and secrets

    Share a password securely without leaving a copy behind. Send a credential or API key once, browser to browser, instead of through email or Slack.

  • Private one-on-one support

    Private support chat that leaves no history. For crisis lines, peer support, and therapy pre-sessions where the device itself must stay clean.
